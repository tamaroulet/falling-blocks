# 落ちものパズル 構造化仕様

## 1. ループと終了条件
| ID | 内容 | 根拠 |
|:--|:--|:--|
| LP-01 | ジャンルは落ちものパズルであり、ミノの出現・操作・落下・固定・ライン消去を繰り返す | L6 |
| LP-02 | 時間はすべて整数ティックで進行し、浮動小数や実時間は用いない | L12-L13 |
| LP-03 | ミノの固定からライン消去を経て次のミノの出現までを同一ティック内で行い、次の周回に入る | L30 |
| LP-04 | 終了条件: 新規ミノの出現位置に既存の固定ブロックが重なり、新規ミノを盤面に配置できない | L133-L134 |
| LP-05 | 終了条件: ブロックがバッファ領域でロックされた | L135 |

| RL-19 | 形状 Z の回転原点および各向きのブロック座標は定義値に従う | 1 向きにつき 4 ブロック | PR-40, PR-41, PR-42, PR-43, PR-44 | L64-L68 |

| RL-22 | 左右入力で 1 マス水平移動する。壁や固定ブロックとの衝突時は移動無効。1 ティックにつき最大 1 回の移動処理を行い、自動リピート処理は行わない | 移動量 1 マス、1 ティックあたり最大 1 回 | - | L85-L86 |

| RL-24 | 下入力中は落下間隔が短縮される。1 ティックにつき最大 1 回のドロップ処理を行い、自動リピート処理は行わない | 3 ティック/マス、1 ティックあたり最大 1 回 | PR-08 | L88 |

| RL-30 | ロック猶予のリセット回数が上限に達した後は、接地中の左右移動や回転は成功するが、ロック猶予タイマーはリセットされない | リセット回数 15 で打ち切り | PR-10 | L96 |
| RL-31 | 接地してロック猶予タイマーが動作している最中に、左右移動や回転により直下のマスが空になった場合は接地状態が解除され、ロック猶予タイマーは停止・リセットされ、リセット回数も 0 に戻る | タイマー 30 ティックへ復帰、リセット回数 0 | PR-09, PR-10 | L97 |
| RL-32 | ミノが盤面に固定された直後、横 10 マス全てがブロックで埋まった行を判定する | 埋まりマス数 10 で成立 | PR-01 | L100-L101 |
| RL-33 | 該当する行を盤面から消去し、消去された行より上にあるブロックを消去行数分だけ下方向へシフトする | 消去行数 1..4 | - | L102 |
| RL-34 | ライン消去によるスコアは消去行数に応じて加算する（1 行=100 点、2 行=300 点、3 行=500 点、4 行=800 点） | 消去行数 1..4 | PR-13, PR-14, PR-15, PR-16 | L103-L107 |
