# 構造化仕様に関する質問

## 質問
| ID | 質問 | 根拠 | 推測で決めない理由 |
|:--|:--|:--|:--|
| Q-01 | 回転原点が (1.5, 1.5) である I ミノと O ミノについて、回転原点を盤面座標 (3, 20) に一致させて出現させると、4 ブロックの盤面座標が .5 を含む非整数になります。盤面の整数セルへどのように対応付けますか（例: 出現時のみ整数オフセットを別途定める / 回転原点の一致とは別の基準座標で配置する / 盤面座標を .5 単位で保持する）。 | L29, L36, L43 | 非整数座標を整数セルへ丸める方法を選ぶと、I ミノと O ミノの出現列と衝突判定がその選択だけで変わり、盤面の占有セルが一意に定まらないため。 |
| Q-02 | ソフトドロップの「入力中」の判定範囲と、3 ティック間隔の計測基準を教えてください。ソフトドロップは 1 ティック分の離散入力で自動連射を設けないと規定される一方、落下処理は「ソフトドロップ入力中は 3 ティックごと」と間隔で規定されています（例: 入力のあったティックのみ 3 ティック周期のカウンタを進める / 入力のあったティックに即座に 1 マス落下させる / 入力を次の落下まで保持する）。 | L91, L97, L102 | 離散入力と 3 ティック周期のどちらを優先するかで、同じ入力列に対する落下マス数とソフトドロップ加点が変わり、スコアと盤面が一意に定まらないため。 |
| Q-03 | ライン消去後の「上部ブロックのシフト」の方向と移動量を教えてください（例: 消去された行より上の全ブロックを、その行より下で消去された行数分だけ下方向へ移動する / 消去行の直上のみを 1 行下げる）。また、バッファ領域（Y=20..21）のブロックもシフト対象に含めますか。 | L105 | シフト量と対象範囲が定まらないと、複数行を同時消去した場合や離れた行を消去した場合の盤面が一意に定まらず、不変条件の検査結果も変わるため。 |
