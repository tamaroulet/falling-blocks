# 落ちものパズル 仕様の確認事項

## 質問

| ID | 質問 | 根拠 | 推測で決めない理由 |
|:--|:--|:--|:--|
| Q-01 | Ready 状態（ミノがまだ出現していない時点）で、フィールドグリッド・アクティブミノ・ネクストキューの公開値は何になりますか。アクティブミノが存在しないことをどう表しますか | L122-L128, L138-L140 | GDD は数値データ（スコア・累計消去ライン数・経過ティック数）の初期値を 0 と定めるのみで、ミノが存在しない時点のアクティブミノとネクストキューの公開値を定めていないため |
| Q-02 | 左右移動・回転・ソフトドロップの各入力操作は、次に受けた「ティックを進める」操作の①で消費されますか。また「ティックを進める」で 2 以上のティック数を与えた場合、それらの入力はどのティックに適用されますか（先頭のティックのみか、全ティックか、ほかか） | L98, L101, L129-L135 | GDD は入力が 1 ティック分の離散入力・ティックごとの真偽値であることのみを定め、入力を受けてからティック処理で消費されるまでの保持規則と、複数ティックを一度に進めた場合の適用先を定めていないため |
