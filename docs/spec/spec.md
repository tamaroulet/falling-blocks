# 落ちものパズル 構造化仕様

## 1. ループと終了条件

| ID | 内容 | 根拠 |
|:--|:--|:--|
| LP-01 | ジャンルは落ちものパズル。ミノの出現 → 操作（左右移動・回転・ソフトドロップ）→ 自然落下 → 接地 → ロック（盤面へ固定）→ ライン消去判定 → 次ミノ出現、を繰り返す | L6, L82, L87, L90, L91, L96 |
| LP-02 | 時間はすべて整数ティックで進行し、1 ティック進めるごとに自然落下間隔とロック猶予のタイマーが進む | L12-L13, L86-L87, L91 |
| LP-03 | 終了条件: 新規ミノの出現位置（初期配置領域）に既存の固定ブロックが重なっており、新規ミノを盤面に配置できない場合、ゲームを終了する | L127-L128 |
| LP-04 | 終了条件: ブロックがバッファ領域（Y >= 20）でロックされた場合、ゲームを終了する | L129 |

## 3. 規則と計算式

| ID | 規則・式 | 境界値 | 参照パラメーター | 根拠 |
|:--|:--|:--|:--|:--|
| RL-01 | 盤面は幅 10 マス × 高さ 20 マス（表示領域 Y=0..19）で、最上部の上側に 2 行分の出現・操作用バッファ領域（Y=20..21）を持ち、内部データ上は 10 × 22 行とする | X=0..9、Y=0..21（表示領域 Y=0..19、バッファ Y=20..21） | PR-01, PR-02, PR-03 | L7-L9 |
| RL-02 | 座標系は原点を左下 (0, 0) とし、X 軸は右方向 (0..9)、Y 軸は上方向 (0..21) とする | X=0 が左端、X=9 が右端、Y=0 が最下段、Y=21 が最上段 | PR-01, PR-02, PR-03 | L10 |
| RL-03 | 各マスのセル状態は「空」または「固定ブロック」のいずれかとする | 2 値 | - | L11 |
| RL-04 | 時間はすべて整数ティックで進行し、浮動小数や実時間は用いない | 最小単位 1 ティック | - | L12-L13 |
| RL-05 | 乱数は決定論的な XorShift32 を用いる。32 ビット符号なし状態 x に対し x ^= x << 13、x ^= x >> 17、x ^= x << 5 を順に適用（各演算は 32 ビットで切り詰める）した値を次の状態かつ出力とする | 状態 x は 0 以外の 32 ビット値（0..4294967295） | - | L16-L17 |
| RL-06 | 出現生成規則（7-Bag ランダマイザ）: I, O, T, S, Z, J, L の 7 種類を 1 セットとし、XorShift32 の出力で Fisher-Yates シャッフル（i = 6 から 1 へ、j = 乱数 mod (i + 1) として要素 i と要素 j を交換）してから順に取り出す | i=6..1、j=0..i、1 セットは 7 個 | PR-13 | L21, L22-L23 |
| RL-07 | 1 セットを消費し切ったら、新たな 7 種類のセットを生成・シャッフルして補充する | セット残数 0 で補充 | PR-13 | L24 |
| RL-08 | 全てのミノは 4 つの正方形ブロックで構成される。種類は I, O, T, S, Z, J, L の 7 種類 | ブロック数 4、種類数 7 | PR-13 | L19-L20 |
| RL-09 | 出現初期位置: フィールド幅の中央、バッファ領域（Y=20）に水平方向で初期配置する | Y=20、X は盤面幅 10 の中央 | PR-01, PR-03 | L25-L26 |
| RL-10 | 出現時の向きは初期回転状態（向き 0）とする | 向き 0 | - | L27 |
| RL-11 | 各テトロミノは 4 方向（向き 0, 向き R, 向き 2, 向き L）ごとのブロック座標 (x, y) と、回転原点 (x, y) を持つ | 1 方向あたり 4 ブロック、4 方向 | PR-14, PR-15, PR-16, PR-17, PR-18, PR-19, PR-20, PR-21, PR-22, PR-23, PR-24, PR-25, PR-26, PR-27, PR-28, PR-29, PR-30, PR-31, PR-32, PR-33, PR-34, PR-35, PR-36, PR-37, PR-38, PR-39, PR-40, PR-41, PR-42, PR-43, PR-44, PR-45, PR-46, PR-47, PR-48 | L30 |
| RL-12 | 左右移動: 左／右入力で 1 マス水平移動する。壁や固定ブロックとの衝突時は移動無効 | 移動量 ±1 マス、X=0..9 の範囲外は無効 | PR-01 | L82-L83 |
| RL-13 | 回転: 時計回りおよび反時計回りの 90 度回転を行う。回転先に壁や固定ブロックがある場合は回転無効とし、位置の補正移動は行わない | 90 度単位、向きは 0 → R → 2 → L の循環 | - | L84 |
| RL-14 | ソフトドロップ: 下入力中は落下間隔が 3 ティック／マスに短縮される | 3 ティック／マス | PR-05 | L85 |
| RL-15 | 重力: ミノは一定のティック間隔ごとに 1 マス自然落下する。初期落下速度は 60 ティック／マス | 60 ティック／マス、1 回につき 1 マス | PR-04 | L86-L88 |
| RL-16 | 接地: 下方向へ移動できなくなった状態を接地とする | 直下が壁（Y=0 の下）または固定ブロック | - | L89-L90 |
| RL-17 | ロックダウン: 接地後、ロック猶予時間 30 ティックが経過すると位置が確定し、盤面へ固定される | 30 ティック | PR-06 | L91 |
| RL-18 | ロック猶予中に左右移動や回転が成功した場合、猶予タイマーをリセットする。リセット回数は最大 15 回まで | リセット回数 0..15 | PR-07 | L92 |
| RL-19 | ライン消去判定: ミノが盤面に固定された直後、横 10 マス全てがブロックで埋まった行を判定する | 1 行あたり 10／10 マス | PR-01 | L95-L96 |
| RL-20 | 該当する行を盤面から消去し、消去された行より上にあるブロックを消去行数分だけ下方向へシフトする | 消去行数 1..4、シフト量 = 消去行数 | - | L97 |
| RL-21 | スコアリング: 1 ライン消去 100 点、2 ライン消去 300 点、3 ライン消去 500 点、4 ライン消去 800 点 | 同時消去行数 1..4 | PR-08, PR-09, PR-10, PR-11 | L98, L99-L102 |
| RL-22 | ソフトドロップによる落下は 1 マスにつき 1 点を加算する | 1 点／マス | PR-12 | L103 |
| RL-23 | 不変条件: 消去ライン数 × 10 ＋ 盤面ブロック数 ＝ 4 × ロックしたミノ数（ゲーム中、いかなる操作やティック進行においても厳密に成立する） | 等式が常に成立 | PR-01 | L104-L106 |
