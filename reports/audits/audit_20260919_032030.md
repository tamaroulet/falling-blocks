指摘2: 盤面境界の異常系を見ていない

指摘3: NewGameState_SatisfiesLineInvariant が張りぼて化している

- どう直すか: 少なくとも1回ロックが発生する最小シナリオを実行し、(LinesCleared*10)+blocks == 4*locks を直接検証。locks を観測できないなら計測 API を追加するか、代替で「1ロック直後の blocks が4増える」等の観測可能な形に落とす。乗算の桁あふれを防ぐため checked 文脈や長整数型での演算も確認。
