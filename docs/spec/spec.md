# 落ちものパズル falling-blocks 構造化仕様

## 1. ループと終了条件
| ID | 内容 | 根拠 |
|:--|:--|:--|
| LP-01 | 落ちものパズルとして、1 ティックを最小単位に処理を繰り返す。1 ティックの処理は厳密に定められた順序で実行する | L6, L99-L100 |
| LP-02 | 1 ティックの処理順序は ①入力の取り込み → ②移動・回転の適用 → ③落下処理 → ④接地判定とロック猶予 → ⑤固定判定 → ⑥ライン消去判定とシフト → ⑦新しいミノの出現 → ⑧ゲームオーバー判定 | L101-L108 |
| LP-03 | Playing へ遷移したティックでは ①〜⑥ を実行せず、最初に新しい 7-Bag を生成してネクストキューを補充したうえで ⑦ と ⑧ を実行し、経過ティック数を 0 とする | L141 |
| LP-04 | 次にティックを進めた時点から ①〜⑧ を実行し、経過ティック数を 1 とする | L142 |
| LP-05 | 終了条件は、固定したミノの 4 マスすべてが Y>=20 にあるとき、または新規出現位置の 4 マスのいずれかに既存の固定ブロックが重なり配置できないとき。判定は固定または新規出現が発生したティックのみ実行する | L108, L143-L145 |
| LP-06 | GameOver 到達後はティック進行を含むすべての操作を無視し、ループを進めない | L149 |
