# 落ちものパズル 構造化仕様

## 1. ループと終了条件
| ID | 内容 | 根拠 |
|:--|:--|:--|
| LP-01 | 落ちものパズルとして進行し、時間はすべて整数ティックで進み、浮動小数や実時間は用いない | L6, L12-L13 |
| LP-02 | 1 ティックの処理は厳密に ①入力の取り込み → ②移動・回転の適用 → ③落下処理 → ④接地判定とロック猶予の処理 → ⑤固定判定 → ⑥ライン消去判定とシフト → ⑦新しいミノの出現 → ⑧ゲームオーバー判定 の順で実行する | L98-L99 |

| LP-05 | GameOver 到達後は、いかなる移動・回転・ドロップ・ティック進行操作を受けても内部状態を変更せず無視する | L146-L147 |

## 3. 規則と計算式
| ID | 規則・式 | 境界値 | 参照パラメーター | 根拠 |
|:--|:--|:--|:--|:--|
| RL-01 | 盤面は幅 10 マス × 表示高さ 20 マス（表示領域 Y=0..19）に、上側 2 行の出現・操作用バッファ領域（Y=20..21）を加えた内部計 22 行とする。原点は左下 (0, 0)、X 軸は右方向、Y 軸は上方向 | X = 0..9、Y = 0..21 | PR-01, PR-02, PR-03, PR-04, PR-05, PR-06 | L7-L10 |
| RL-02 | 各マスのセル状態は「空」または「固定ブロック」のいずれかをとる | 2 値 | - | L11 |
| RL-03 | 時間は整数ティックでのみ進行する | ティックは整数 | - | L12-L13 |
| RL-04 | 乱数は決定論的な XorShift32 を用いる。32 ビット符号なし整数 x に対し `x ^= x << 13; x ^= x >> 17; x ^= x << 5;` の順に更新し、更新後の値を乱数値として返す | x は 32 ビット符号なし整数 | - | L16-L17, L19 |
| RL-05 | シード未指定時の既定値は 1。シードまたは内部状態として 0 が与えられた場合は 1 に置き換えて初期化する | 0 のとき 1 に置換 | PR-07, PR-08 | L18 |
| RL-06 | 全てのミノは 4 つの正方形ブロックで構成され、種類は I, O, T, S, Z, J, L の 7 種類 | 4 ブロック / 7 種類 | PR-22, PR-23 | L20-L22 |
| RL-07 | 出現生成は 7-Bag ランダマイザによる。シャッフル前の初期配列を `[I, O, T, S, Z, J, L]` とし、7 種類 1 セットを XorShift32 によりシャッフルして順に取り出す | 1 セット = 7 個 | PR-09 | L23-L25 |
| RL-08 | シャッフルは Fisher-Yates を用い、末尾インデックス i（6 から 1 まで降順）について `j = XorShift32() % (i + 1)` を求め、インデックス i と j のミノを交換する。1 セット生成につき乱数を 6 回消費する | i = 6..1、j = 0..i、乱数消費 6 回 | - | L26 |
| RL-09 | ネクストキューの残りが 0 個になったティックの出現フェーズで、新しい 7-Bag を生成してキューに追加補充する | 残り 0 個 | - | L27 |
| RL-10 | 出現は、各ミノの回転原点を盤面座標 (3, 20) に一致させ、向き 0（初期回転状態）で行う | 回転原点 = (3, 20)、向き 0 | PR-10, PR-11 | L28-L30 |
| RL-11 | 各テトロミノの向き 0 / R / 2 / L におけるブロック座標および回転原点は、外部パラメーターの形状定義に従う | 7 種類 × 4 方向 | PR-24, PR-25, PR-26, PR-27, PR-28, PR-29, PR-30, PR-31, PR-32, PR-33, PR-34, PR-35, PR-36, PR-37, PR-38, PR-39, PR-40, PR-41, PR-42, PR-43, PR-44, PR-45, PR-46, PR-47, PR-48, PR-49, PR-50, PR-51, PR-52, PR-53, PR-54, PR-55, PR-56, PR-57, PR-58 | L33 |
| RL-12 | 時計回り回転は向き `0 → R → 2 → L → 0` の順に巡回する | 4 状態の巡回 | - | L84-L85 |
| RL-13 | 反時計回り回転は向き `0 → L → 2 → R → 0` の順に巡回する | 4 状態の巡回 | - | L86 |
| RL-14 | 左右移動: 左/右入力で 1 マス水平移動する。移動後の 4 マスが壁や固定ブロックと重なる場合は失敗とし、位置を変更しない | 移動量 1 マス | - | L94-L95 |
| RL-15 | 回転: 時計回りおよび反時計回りの 90 度回転。回転後の 4 マスが壁・床・固定ブロックのいずれかと重なる場合は失敗とし、向きと位置を変更しない。補正のための移動は一切行わない | 90 度単位、補正移動 0 マス | - | L96 |
| RL-16 | 左右移動・回転・ソフトドロップはいずれも 1 ティック分の離散入力とし、自動連射は設けない | 1 ティックにつき 1 回 | - | L97 |
| RL-17 | ①入力の取り込み: 左右移動、回転、ソフトドロップ判定を取り込む | - | - | L100 |
| RL-18 | ②移動・回転の適用: 衝突時は位置・向きを変更せず失敗とする | - | - | L101 |
| RL-19 | ③落下処理: ソフトドロップ入力中は 3 ティックごと、通常時は 60 ティックごとに 1 マス落下する | 3 ティック / 60 ティック | PR-12, PR-13 | L102 |
| RL-20 | ③落下処理: ソフトドロップで落下したティックは自然落下タイマーを 0 に戻す。空中で移動・回転が成功しても自然落下タイマーはリセットせず維持する | タイマー = 0 | PR-12 | L102 |
| RL-21 | ④接地判定: 直下が空なら猶予タイマーを 30 ティックに戻し、リセット回数を 0 に戻す | タイマー = 30、リセット回数 = 0 | PR-14 | L103 |
| RL-22 | ④ロック猶予: 接地中で②の移動または回転が成功した場合、リセット回数が 15 未満なら猶予タイマーを 30 ティックに戻しリセット回数を 1 増やす。15 に達している場合はタイマーを戻さない | リセット回数 < 15 / = 15 | PR-14, PR-15 | L103 |
| RL-23 | ④ロック猶予: 接地中で移動も回転もしていないか失敗した場合は猶予タイマーを 1 減らす | 1 ティックにつき -1 | PR-14 | L103 |
| RL-24 | ⑤固定判定: 猶予タイマー満了時、ミノを盤面へ固定する | タイマー満了 | PR-14 | L104 |
| RL-25 | ⑥ライン消去判定とシフト: 固定が発生したティックのみ判定し、横 10 マス埋まった行を消去して上部ブロックをシフトする | 行の占有数 = 10 | PR-01 | L105 |
| RL-26 | ⑦新しいミノの出現: 固定が発生したティックのみ、遅延 0 ティックで次のミノを盤面座標 (3, 20) に出現させる。ネクストキューが 0 個なら事前に新しい 7-Bag を補充する | 遅延 = 0 ティック、キュー残り 0 個 | PR-10 | L106 |
| RL-27 | ⑧ゲームオーバー判定: 固定したミノの 4 マスすべてが Y >= 20 のとき、または新規出現時に 4 マス中 1 マスでも既存ブロックと重なり配置できないとき | Y >= 20、重なり 1 マス以上 | - | L107 |
| RL-28 | スコア加算: 同時消去ライン数 1 / 2 / 3 / 4 に対し、それぞれ 100 / 300 / 500 / 800 点を加算する | 消去ライン数 = 1..4 | PR-16, PR-17, PR-18, PR-19 | L110-L114 |
| RL-29 | スコア加算: ソフトドロップによりミノが下方向に 1 マス落下したティックごとに 1 点を加算する | 1 マスにつき 1 点 | PR-20 | L115 |
| RL-30 | 不変条件: 消去ライン数 × 10 ＋ 盤面ブロック数 ＝ 4 × ロックしたミノ数。いかなる操作やティック進行においても厳密に成立する | 常時成立 | PR-01, PR-22 | L116-L118 |
| RL-31 | 公開インターフェースに存在する操作のうち、未規定な状況における入力に対しては内部状態を変更せず何もしない（No-op / 無視） | 状態変化なし | - | L146 |
| RL-32 | 左右同時入力など矛盾する操作を同一ティックに受けた場合は、入力を無効として移動しない | 同時入力は無効 | - | L148 |
