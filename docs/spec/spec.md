# 落ちものパズル 構造化仕様

## 1. ループと終了条件
| ID | 内容 | 根拠 |
|:--|:--|:--|
| LP-01 | ジャンルは落ちものパズルであり、ティック進行で盤面と操作中ミノを更新し続ける | L6 |
| LP-02 | 1 ティックの処理は ①入力の取り込み ②移動・回転の適用 ③落下処理 ④接地判定とロック猶予 ⑤固定判定 ⑥ライン消去判定とシフト ⑦新しいミノの出現 ⑧ゲームオーバー判定 の順で厳密に実行する | L99-L100 |

## 3. 規則と計算式
| ID | 規則・式 | 境界値 | 参照パラメーター | 根拠 |
|:--|:--|:--|:--|:--|
| RL-01 | 盤面は幅 10 マス × 高さ 20 マス（表示領域 Y=0..19）に、最上部の上側 2 行分の出現・操作用バッファ領域（Y=20..21）を加えた内部計 22 行とする | X=0..9, Y=0..21 | PR-01, PR-02, PR-03 | L7-L9 |
| RL-02 | 座標系は原点を左下 (0, 0) とし、X 軸は右方向 (0..9)、Y 軸は上方向 (0..21) とする | X 最小 0 / 最大 9, Y 最小 0 / 最大 21 | PR-01, PR-02, PR-03 | L10 |
| RL-03 | 各マスのセル状態は「空」または「固定ブロック」のいずれかである | - | - | L11 |
| RL-04 | 時間はすべて整数ティックで進行し、浮動小数や実時間は用いない | ティックは整数のみ | - | L12-L13 |
| RL-05 | 乱数は決定論的な XorShift32 とし、32 ビット符号なし整数 x を x ^= x << 13; x ^= x >> 17; x ^= x << 5; の順に更新し、更新後の値を乱数値として返す | 32 ビット符号なし整数の範囲で演算 | - | L16-L17, L19 |
| RL-06 | シード未指定時の既定値は 1 とし、シードまたは内部状態として 0 が与えられた場合は 1 に置き換えて初期化する | 0 のとき 1 に置換 | PR-04 | L18 |
| RL-07 | すべてのミノは 4 つの正方形ブロックで構成され、種類は I, O, T, S, Z, J, L の 7 種類である | ブロック数 = 4, 種類数 = 7 | - | L20-L22 |
| RL-08 | 7-Bag は初期配列を I, O, T, S, Z, J, L の順とし、7 種類を 1 セットとして XorShift32 によりシャッフルして順に取り出す | 1 セット = 7 個 | PR-05 | L23-L25 |
| RL-09 | シャッフルは Fisher-Yates を用い、末尾インデックス i（6 から 1 まで降順）について j = XorShift32() % (i + 1) を求め、インデックス i と j のミノを交換する。1 回のセット生成につき乱数を 6 回消費する | i = 6..1, j = 0..i, 乱数消費 = 6 回 | PR-05 | L26 |
| RL-10 | ネクストキューの残りが 0 個になったティックの出現フェーズで、新しい 7-Bag を生成してキューに追加補充する | 残り 0 個のとき補充 | PR-05 | L27 |
| RL-11 | 回転は幾何マトリクスから回転後の向きの相対座標を引き直すことで行う。回転原点は幾何マトリクス定義の基準であって実行時の座標計算には用いない | - | PR-18, PR-23, PR-28, PR-33, PR-38, PR-43, PR-48 | L28-L29 |
| RL-12 | 盤面座標は基準位置 (Bx, By) と相対座標 (x, y) から (Bx + x, By + y) で求める。結果は常に整数とする | 常に整数 | - | L30 |
| RL-13 | 出現時の基準位置は (3, 19)、向きは初期回転状態（向き 0）とする。各ミノの向き 0 のブロックはバッファ領域 Y=20..21 内に配置される | 基準位置 (3, 19), 配置 Y=20..21 | PR-06 | L31 |
| RL-14 | 各テトロミノの 4 方向（向き 0, R, 2, L）におけるブロック座標 (x, y) および回転原点 (x, y) は外部パラメーターの幾何マトリクスで定義する | 4 方向 × 4 ブロック | PR-19, PR-24, PR-29, PR-34, PR-39, PR-44, PR-49 | L34 |
| RL-15 | 左右移動: 左/右入力で 1 マス水平移動する。移動後の 4 マスが壁や固定ブロックと重なる場合は失敗とし位置を変更しない | 移動量 = 1 マス | - | L95-L96 |
| RL-16 | 回転: 時計回りおよび反時計回りの 90 度回転。回転後の 4 マスが壁・床・固定ブロックのいずれかと重なる場合は失敗とし、向きと位置を変更しない。補正移動は一切行わない | 回転角 = 90 度 | - | L97 |
| RL-17 | 左右移動・回転は 1 ティック分の離散入力とし、自動連射は設けない。ソフトドロップ入力はティックごとの真偽値とする | 1 ティックにつき 1 回 | - | L98 |
| RL-18 | ①入力の取り込み: 左右移動、回転、ソフトドロップ判定を取り込む | - | - | L101 |
| RL-19 | ②移動・回転の適用: 衝突時は位置・向きを変更せず失敗とする | - | - | L102 |
| RL-20 | ③落下処理: ソフトドロップ入力が真のティックはソフトドロップカウンタを 1 増やし、3 に達したら 1 マス落下させてカウンタを 0 に戻す。入力が偽のティックはカウンタを 0 に戻す。通常時は 60 ティックごとに 1 マス自然落下する。自然落下カウンタはソフトドロップと独立に進み、ソフトドロップによる落下ではリセットしない。空中で移動・回転が成功しても自然落下カウンタはリセットせず維持する | ソフトドロップカウンタ = 3 で落下, 自然落下カウンタ = 60 で落下 | PR-07, PR-08 | L103 |
| RL-21 | ④接地判定とロック猶予: 直下が空なら猶予タイマーを 30 ティックに戻しリセット回数を 0 に戻す。接地中で②の移動または回転が成功した場合、リセット回数が 15 未満なら猶予タイマーを 30 ティックに戻しリセット回数を 1 増やす。15 に達している場合はタイマーを戻さない。接地中で移動も回転もしていないか失敗した場合は猶予タイマーを 1 減らす | リセット回数 < 15 で戻す, = 15 で戻さない, タイマー 30..0 | PR-09, PR-10 | L104 |
| RL-22 | ⑤固定判定: 猶予タイマー満了時にミノを盤面へ固定する | タイマー = 0 で固定 | PR-09 | L105 |
| RL-23 | ⑥ライン消去判定とシフト: 固定が発生したティックのみ判定する。横 10 マス埋まった行を消去し、消去されなかった行のうち消去された行より上にある各行（バッファ領域 Y=20..21 を含む）を、その行より下で消去された行の数だけ Y の小さい方向へ移動する。移動後、盤面の最上段 Y=21 から消去行数分は空行とする | 消去条件 = 横 10 マス, 消去行数 = 0..4 | PR-01 | L106 |
| RL-24 | ⑦新しいミノの出現: 固定が発生したティックのみ、遅延 0 ティックで即座に次のミノを基準位置 (3, 19) に出現させる。ネクストキューが 0 個なら事前に新しい 7-Bag を補充する | 遅延 = 0 ティック, キュー 0 個で補充 | PR-06, PR-17 | L107 |
| RL-25 | ⑧ゲームオーバー判定: 固定したミノの 4 マスすべてが Y>=20 のとき、または新規出現時に 4 マス中 1 マスでも既存ブロックと重なり配置できないとき | Y>=20, 重なり 1 マス以上 | PR-03 | L108 |
| RL-26 | スコアリング: 1 ライン消去は 100 点、2 ライン消去は 300 点、3 ライン消去は 500 点、4 ライン消去は 800 点を加算する | 消去行数 = 1..4 | PR-11, PR-12, PR-13, PR-14 | L111-L115 |
| RL-27 | スコアリング: ソフトドロップによりミノが下方向に 1 マス落下したティックごとに 1 点を加算する | 1 マスにつき 1 点 | PR-15 | L116 |
| RL-28 | 不変条件: 消去ライン数 × 10 ＋ 盤面ブロック数 ＝ 4 × ロックしたミノ数。ゲーム中、いかなる操作やティック進行においてもこの等式が厳密に成立しなければならない | 常時成立 | PR-01 | L117-L119 |
| RL-29 | 公開インターフェースに存在する操作のうち、未規定な状況における入力に対しては内部状態を変更せず何もしない（No-op / 無視） | 状態変化なし | - | L148 |
| RL-30 | 左右同時入力など矛盾する操作を同一ティックに受けた場合は、入力を無効として移動しない | 同一ティック内 | - | L150 |
