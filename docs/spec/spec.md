# 落ちものパズル 構造化仕様

## 1. ループと終了条件

| ID | 内容 | 根拠 |
|:--|:--|:--|
| LP-01 | ジャンルは落ちものパズル。1 ティックの処理は厳密に①〜⑧の順序で実行する | L6, L99-L100 |
| LP-02 | 主ループは Ready（開始待機）→ Playing（操作・進行中）→ GameOver（終了）の 3 状態で進む | L138-L139 |
| LP-03 | Playing へ遷移したティックでは①〜⑥を実行せず、最初に新しい 7-Bag を生成してネクストキューを補充した上で⑦と⑧のみを実行し、経過ティック数を 0 とする | L140-L141 |
| LP-04 | 次にティックを進めた時点から①〜⑧を実行し、そのティックの経過ティック数を 1 とする | L142 |
| LP-05 | 終了条件 1: 固定したミノの 4 マスすべてが Y >= 20 のとき GameOver とする（⑧で判定） | L108, L143-L144 |
| LP-06 | 終了条件 2: 新規出現時に 4 マス中 1 マスでも既存の固定ブロックと重なり配置できないとき GameOver とする（⑧で判定） | L108, L145 |
| LP-07 | GameOver 到達後はティック進行を含むすべての操作が無視され、ループは進行しない | L148-L149 |
