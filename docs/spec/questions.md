# 落ちものパズル 仕様の確認事項

## 質問

| ID | 質問 | 根拠 | 推測で決めない理由 |
|:--|:--|:--|:--|
| Q-01 | Ready から Playing へ遷移する契機は何ですか（選択肢: 開始操作の入力を受けたとき／シードの注入が行われたとき／最初のティックが進んだとき／その他） | L125-L126 | GDD は Ready → Playing → GameOver という順序だけを示し、遷移の契機を書いていないため、いつ Playing に入るかが一意に決まらない |
| Q-02 | 出現初期位置「フィールド幅の中央、バッファ領域（Y=20）」とは、第 3 章の 4×4 座標系のどの点を盤面のどの座標に合わせることですか（選択肢: 4×4 枠の原点 (0, 0) を盤面 (3, 20) に置く／占有セルの最下段が Y=20 になるように置く／その他） | L25-L26, L30 | 第 3 章の形状座標は 4×4 の内部座標で書かれており、それを盤面座標へ対応させる規則が GDD に無いため、出現時に占有するマスが一意に決まらない |
| Q-03 | XorShift32 のシフト量（例: 13, 17, 5）と、乱数値からバッグ内の交換位置を決める手順（シャッフルアルゴリズムと剰余の取り方、乱数を消費する回数）はどれですか | L16-L17, L22-L23 | GDD は「XorShift32 によりシャッフルする」とのみ書き、シフト量とシャッフル手順が書かれていないため、「同一シードでは常に同一の出現順序」という要件を満たす順序が一意に定まらない |
| Q-04 | ネクストキューとして公開するミノの個数は何個ですか（選択肢: 1 個／3 個／6 個／バッグの残り全部） | L113 | GDD は「次に出現するミノのリスト」とのみ書き、公開する個数が書かれていないため |
| Q-05 | 「初期落下速度は 60 ティック／マス」の「初期」は、途中で落下速度が変化することを意味しますか。変化する場合、その契機と変化後の値は何ですか | L88 | 「初期」という語が変化の存在を示唆する一方、変化の条件・変化後の値が GDD に書かれていないため |
| Q-06 | ソフトドロップの 1 点は、どの落下に対して加算されますか（選択肢: 下入力中に落下した 1 マスごと／下入力による落下だけでなく自然落下も含む／その他） | L85, L103 | GDD は「ソフトドロップ: 1 マス落下につき 1 点」とのみ書き、加点対象の落下の範囲が書かれていないため |
| Q-07 | ミノが盤面へ固定されてからライン消去を経て次のミノが出現するまでに、何ティックの遅延がありますか（選択肢: 0 ティック（同一ティック内で完了）／固定後に n ティック／その他） | L91, L95-L97 | GDD は処理の順序のみを書き、これらの処理に要するティック数が書かれていないため、経過ティック数と盤面状態の対応が一意に決まらない |
| Q-08 | ロック猶予のリセット回数が上限 15 回に達した後、接地状態で左右移動や回転が成功した場合はどうなりますか（選択肢: 移動・回転は成功するが猶予タイマーはリセットされない／移動・回転自体を無効にする／その時点で即座に固定する） | L91-L92 | GDD は上限が 15 回であることだけを書き、上限到達後の挙動が書かれていないため |
| Q-09 | 接地してロック猶予が動いている最中に、左右移動や回転の結果として直下が空になった場合、ロック猶予タイマーとリセット回数はどう扱いますか（選択肢: 猶予を打ち切り通常の落下に戻し回数も 0 に戻す／猶予は打ち切るが回数は保持する／猶予タイマーは動き続ける） | L89-L92 | GDD は接地の定義と猶予のリセット条件のみを書き、接地が解除された場合の扱いが書かれていないため |
| Q-10 | 左右移動入力・ソフトドロップ入力は 1 回の入力で 1 回だけ作用しますか、それとも押下継続中はティックごとに繰り返し作用しますか。繰り返す場合、その間隔は何ティックですか | L82-L83, L85, L119, L122 | GDD は入力に対する 1 回分の効果だけを書き、入力が継続した場合のティックごとの扱いが書かれていないため |
